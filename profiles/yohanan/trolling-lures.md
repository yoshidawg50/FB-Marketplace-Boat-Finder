# Yohanan's Trolling Lures (owned)

Owned trolling spread. Link each to its universal
[lure](../../lures/) note for running specs (speed, depth, setback, leader). How
to decide which to pull: [bluefin trolling](../../species/bluefin-trolling.md)
and [trolling](../../techniques/trolling.md).

## Swimmers / divers → [Rapala Husky Magnum](../../lures/rapala-husky-magnum.md)
- **Rapala Husky Magnum 20 (HM20)** — green with mackerel stripes — ~20 ft
  running depth by the model-number convention. **Gap:** the universal note
  only documents HM25/HM15 running specs; HM20 specs not yet recorded.
- **Rapala Husky Magnum 30 (HM30)** — purple — ~30 ft running depth by the
  model-number convention. **Gap:** same — HM30 specs not yet recorded in the
  universal note.

## High-speed → [Mad Mac](../../lures/mad-mac.md)
- One of each Nomad Madmacs size, **200 through the largest size made** —
  exact sizes above 200 and colors not yet recorded. **Gap:** the universal
  Mad Mac note only documents running specs for the 200 and 130 — nothing
  for whatever's larger than 200.

## Cedar / skirts / feathers / bars → [cedar plug](../../lures/cedar-plug.md)
- **Cedar plug** — smaller than the standard 6" size the universal note
  covers (exact size not yet recorded).

## Spread rules
- Runs from [Cameron's Panga Marine Marquesas 22](../cameron/boat.md) — see
  [Cameron's boat](../cameron/boat.md) for holder geometry and spread rules
  (no outriggers, 2–3 lures, furthest-back lure out of the elevated shotgun).

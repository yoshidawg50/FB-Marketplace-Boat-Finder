# Yohanan's Rods — 4 Setups

Rod/reel inventory. The **braid weight listed is what's spooled on that reel
now**; top shots / leaders change per application. Class terms link to
[gear classes](../../tackle/gear-classes.md); see
[rod & reel selection](../../tackle/rod-and-reel-selection.md) for the general
logic.

## 1. Lexa 300 setup
- **Rod:** Californian inshore rod, **9'0", 15–25 lb rating**.
- **Reel:** Daiwa Lexa 300. **Braid: 50 lb**, optional fluoro leader.
- **Role / gear class:** [workhorse / all-around class](../../tackle/gear-classes.md)
  — general-purpose bait & lure inshore rod.

## 2. Tranx 200 setup
- **Rod:** Phenix Feather, **7'7", 15–35 lb rating, 1/2–3 oz lure weight**.
- **Reel:** Shimano Tranx 200. **Braid: 25 lb**, optional fluoro leader.
- **Role / gear class:** [utility inshore / baitcast class](../../tackle/gear-classes.md)
  — casting hard baits / swimbaits in the 1/2–3 oz range.

## 3. Fathom 40 setup
- **Rod:** Californian rod, **7'6", 70–130 lb rating**.
- **Reel:** Penn Fathom 40. **Braid: 65 lb, topshot: 60 lb mono.**
- **Role / gear class:** [rail-rod / heavy tuna class](../../tackle/gear-classes.md)
  — heavy stand-up work.

## 4. Lexa 500 setup
- **Rod:** Custom deckhand rod, **40–80 lb rating**.
- **Reel:** Daiwa Lexa 500. **Braid: 65 lb**, optional fluoro leader.
- **Role / gear class:** [surface-iron / jig-stick class](../../tackle/gear-classes.md)
  — deckhand-handle casting setup.

# Halco Laser Pro

The Halco Laser Pro is a bibbed trolling minnow — the deep-diving **XDD** bib
version dives hard for its size. It's the lightest lure in Cameron's trolling
box, which makes it a swimmer that fishes the lighter **40–60 lb class**. It
rides the **low gunnel holders** as a diver. Covered here is the **LP190 XDD**
with the 6M+ "crazy deep" bib.

## Running specs

- **Troll speed:** 3–11 kt (optimum 6.5).
- **Running depth:** 20+ ft.
- **Setback:** 11–55 yd, default 27.
- **Leader / top-shot:** 40–60 lb.
- **Notes:** lightest lure in the box at 1-5/8 oz; the 6M+ bib is the "crazy
  deep" diving lip.

## How to run it

A calm-day diver — run it around the 6.5 kt optimum on light line (40–60 lb) from
a **low gunnel holder** so the deep bib does its work, default ~27 yd back. Its
light weight makes it a picky-bite change-up. **When** to reach for a deep diver
versus a swimmer, a spreader bar, or a speed-trolled
[Mad Mac](../lures/mad-mac.md) is decided in
[bluefin trolling](../species/bluefin-trolling.md); general towing mechanics live
in [trolling](../techniques/trolling.md).

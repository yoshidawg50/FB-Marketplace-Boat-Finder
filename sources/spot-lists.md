# GPS Spot Lists — Cameron's spot library

Cameron's curated spot library (raw source for `profiles/cameron/spots.md`).
**Visibility note (2026-08-12):** this repo is public and Cameron waived the
private-only restriction — "none of these spots are secret." The file was
renamed from `spot-lists-PRIVATE-ONLY.md` (that name is false in a public repo).
For any *future* contributor's spot file, re-confirm the waiver or repo
visibility before committing coordinates; default to withholding coords on a
public repo.

Format: `name — LAT deg min.mmm / LON deg min.mmm`. All latitudes N, all longitudes W.
Decimal conversion: `deg + min/60` (negate longitude).
Naming-collision rule (Cameron's): prefix with the closest landmass — "Catalina - X", "Baja - X", "San Diego - X". Exception: the two "400" banks are "East 400"/"West 400" (both Baja offshore, ~44 km apart E–W at the same latitude).
NOT collisions (distinct names, just similar): "475" vs "475 Knuckle"; "300" vs "Bell Bank (300)" vs "300 (The Rampart)"; "179" vs "Tuna Hole (179)"; "220" vs "Double 220". Colloquially ambiguous but distinct: "Kidney Bank (63)" vs "302 (Kidney Bank)".
UNRESOLVED: "The Slide" ×2 — one Catalina front-side shoreline spot, one offshore bank ~6 km away; both closest to Catalina, landmass rule can't separate them. Awaiting Cameron.
Sub-pixel clusters (collapse to ~1 MUR pixel for modeling; keep as distinct waypoints for navigation): Carlsbad AR 1–12, Oceanside AR 1A–1H/2A–2L, Pendleton 1–7, International Reef A–F, Torrey Pines 1–2.
BightSST eval targets: 14 Mile Bank, North + South 9 Mile Bank, Cortes Bank, 302, La Jolla NW Corner, Rockpile, Pyramid Cove, and each of the 6 Coronado Islands spots individually.

# Sources

Provenance for the KB. Everything here is raw input, kept greppable forever —
knowledge is distilled *out* of these into the branch notes, never the reverse.

- **`transcripts/`** — 128 BD Outdoors YouTube transcripts + `_manifest.csv`
  (`video_id, title, status, caption_type, failure_reason, channel,
  upload_date`). Grep these anytime to check a claim against the source.
- **`source-registry.md`** — which voices/channels earn `high` confidence.
- **`extraction-log.md`** — every `video_id` + every `memory-export` section →
  the note(s) it fed, or `skipped: <reason>`. Updated incrementally per commit.
- **`memory-export.md`** — Cameron's exported chat-memory knowledge (the
  live-capture surface; future deltas arrive as `memory-export-YYYY-MM-DD.md`).
- **`bd-transcript-knowledge-proposal.md`** — the completed conditions/planning
  pre-extraction that seeded `conditions/`, `seasonal/`, `planning/`.
- **`spot-lists.md`** — Cameron's spot library (renamed from the PRIVATE-ONLY
  file; repo public, privacy waived 2026-08-12). Raw source for
  `../profiles/cameron/spots.md`.
